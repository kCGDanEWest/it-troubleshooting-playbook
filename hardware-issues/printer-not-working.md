# Printer Not Working Troubleshooting

## Step 1: Check Power and Connections
- Ensure printer is powered on
- Verify USB or network connection

## Step 2: Verify Default Printer
- Go to Devices and Printers
- Ensure correct printer is set as default

## Step 3: Restart Print Spooler
- Open Services
- Restart "Print Spooler"

## Step 4: Reinstall Printer Driver
- Remove printer
- Reinstall latest driver

## Step 5: Test Print
- Print test page

## Resolution
Printer functionality restored after driver reinstall or service restart.
