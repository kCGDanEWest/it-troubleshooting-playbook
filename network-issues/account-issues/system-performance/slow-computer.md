# Slow Computer Troubleshooting

## Step 1: Check CPU Usage
- Open Task Manager
- Identify high CPU processes

## Step 2: Check Memory Usage
- Look for excessive RAM usage

## Step 3: Disable Startup Programs
- Reduce unnecessary startup apps

## Step 4: Disk Cleanup
- Remove temporary files

## Step 5: Restart System
- Reboot to refresh system resources

## Resolution
System performance improved after resource optimization.
