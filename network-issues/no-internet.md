# No Internet Connection Troubleshooting

## Step 1: Check Physical Connection
- Ensure Ethernet cable is plugged in
- Verify Wi-Fi is enabled

## Step 2: Verify IP Address
- Open Command Prompt
- Run: ipconfig
- Confirm system has a valid IP address

## Step 3: Test Connectivity
- Ping default gateway
- Ping external site (google.com)

## Step 4: Restart Network Adapter
- Disable and re-enable adapter

## Step 5: Reset Network Configuration
- Run: ipconfig /release
- Run: ipconfig /renew

## Resolution
Determine if the issue is local, network-related, or ISP-related.
