# No Internet Connection Troubleshooting

## Step 1: Check Physical Connection
- Ensure Ethernet cable is plugged in
- Verify Wi-Fi is enabled

## Step 2: Verify IP Address
- Run: ipconfig
- Confirm system has a valid IP

## Step 3: Test Connectivity
- Ping gateway
- Ping google.com

## Step 4: Restart Adapter
- Disable and re-enable network adapter

## Resolution
Connectivity restored after network reset or configuration fix.
