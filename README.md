# IT Troubleshooting Playbook – Dan West

## Overview

This repository contains a structured troubleshooting playbook designed to simulate real-world IT support scenarios. It includes step-by-step guides for diagnosing and resolving common technical issues across systems, networks, accounts, and hardware.

## Purpose

* Standardize troubleshooting processes
* Provide clear and repeatable solutions
* Demonstrate problem-solving and documentation skills

## Categories

* Account Issues
* Network Issues
* Hardware Issues
* Software Issues
* System Performance

## Skills Demonstrated

* Technical troubleshooting
* Root cause analysis
* IT documentation
* End-user support
